# Боковая панель профиля

Документация по UX и реализации drawer профиля на главном экране календаря.

## Где в коде

| Файл | Роль |
|------|------|
| `ui/screens/CalendarScreen.kt` | `ModalNavigationDrawer`, состояние, жесты, `BackHandler` |
| `ui/profile/ProfileContent.kt` | Содержимое панели |
| `ui/components/CalendarHeader.kt` | Шапка, передаёт `onMenuClick` в логотип |
| `ui/components/NeiroLogo.kt` | Кликабельный круг «N» |

## Как открыть профиль

1. **Свайп слева направо** — начать жест у левого края экрана (любая высота). Панель выезжает **вместе с пальцем** (стандартный жест Material3 `ModalNavigationDrawer`, `gesturesEnabled = true`).
2. **Тап по синему кругу с «N»** в левой части шапки календаря — панель открывается анимацией `drawerState.open()`.

Другие элементы шапки (название месяца, стрелки, колокольчик) профиль **не** открывают. Кнопка «Сегодня» — в карточке выбранного дня над сеткой. Переключатель YClients / архив и «Обновить» — в [CalendarToolbar] над сеткой.

## Как закрыть профиль

- Свайп **влево** (вернуть панель за край экрана).
- Тап по **затемнённой области** справа от панели.
- Системная кнопка **«Назад»** — закрывает drawer, если открыт.

## Когда жест drawer выключен

Пока поверх календаря открыт оверлей, `gesturesEnabled = false`, чтобы жест не мешал диалогам:

- редактирование дня (`DayDetailsDialog`);
- настройки профиля / приложения;
- детализация занятий и прибыли;
- диалог регистрации.

Тап по «N» в шапке по-прежнему может открыть drawer, если шапка видна (не перекрыта полноэкранными настройками).

## Технические заметки

- Ширина панели: **80%** экрана (`ModalDrawerSheet(fillMaxWidth(0.8f))`).
- Контент drawer **всегда** в композиции (без `if (isOpen)`), иначе при первом перетаскивании панель не отрисовывается за пальцем.
- Не использовать кастомный `pointerInput` с порогом открытия вместо `gesturesEnabled` — он не даёт интерактивного «вытаскивания» панели.

## Изменения поведения

При правках UX сначала менять `CalendarScreen.kt` (`ModalNavigationDrawer`, `drawerGesturesEnabled`, `onMenuClick`). Логику профиля и настроек — в `ProfileContent` / `SettingsScreen`.
