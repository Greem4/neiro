## Цена групповых занятий, кроме интенсива

**Как сейчас.** Группа узнаётся по `activity_id` (с 31.10.2026), но деньги за
любую группу считаются как за интенсив: ставка за ребёнка из профиля,
`pricePerIntensiveChild` (`YClientsCalendarSync.mergeIntensivesFromApi`).

**Как правильно.** Сумма группы — цена услуги каждого ребёнка из YClients
(`services[].cost`), а ставка интенсива — только для интенсива. Нейройога
стоит 1700, «Мы вместе» — 1250–2500 ([GAPS.md § 1](pricing-from-api/GAPS.md#1-приложение-знает-3-вида-работы-в-фирме--44-услуги)).

**Почему не сделано.** У нынешнего специалиста групп кроме интенсива нет —
владелец решил 31.10.2026 «сильно не париться». Вернуться, когда появится
специалист с группами; вместе с этим стоит решить карту `service_id → ставка`
([GAPS.md § Вопросы](pricing-from-api/GAPS.md)).

## Откат перевода архива в «Оплачено» — днём целиком

**Как сейчас.** Откат возвращает каждый переведённый день к содержимому до
перевода целиком (`CalendarDataStore.rollbackArchiveMigration`). Ручная правка
такого дня, сделанная после перевода, откатится вместе с ним.

**Как правильно.** Откатывать только поля, которые поменял перевод: хранить не
исходный день, а пары «запись → прежний статус» и возвращать статус, лишь если
запись с тех пор не трогали.

**Почему не сделано.** Откат нужен на случай, если правило перевода окажется
неверным, — то есть сразу после выхода версии, когда ручных правок поверх ещё
нет. Сложность пообъектного отката этого не окупает.
