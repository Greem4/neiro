# Интеграция с YClients API

## Что добавлено

1. **Сетевой слой** (`data/network/`):
   - `YClientsModels.kt` — модели данных API (запросы/ответы)
   - `YClientsApi.kt` — Retrofit интерфейс
   - `YClientsClient.kt` — настройка OkHttp + Retrofit
   - `TokenStorage.kt` — безопасное хранение токенов (EncryptedSharedPreferences)
   - `YClientsRepository.kt` — репозиторий для работы с API

2. **UI авторизации** (`ui/auth/`):
   - `AuthScreen.kt` — экран входа
   - `AuthViewModel.kt` — логика авторизации

3. **Синхронизация** (`ui/sync/`):
   - `SyncViewModel.kt` — синхронизация записей с локальным календарём

4. **Интеграция в приложение**:
   - Кнопка «YClients» добавлена в боковую панель профиля
   - Overlay для экрана авторизации в CalendarScreen

## Настройка

### 1. Получение Partner Token

1. Зайдите на [developer.yclients.com](https://developer.yclients.com/)
2. Зарегистрируйтесь как разработчик
3. Создайте приложение в маркетплейсе интеграций
4. Скопируйте **Partner Token** из настроек аккаунта

### 2. ID компании

ID компании берётся из URL вашего YClients:
```
https://yclients.com/timetable/520135#main_date=...
                            ^^^^^^
                            это ID
```

### 3. Вход в приложение

1. Откройте боковую панель профиля
2. Нажмите кнопку **«YClients»**
3. Нажмите шестерёнку (⚙️) и введите:
   - Partner Token
   - ID компании
4. Введите логин и пароль от YClients
5. После входа нажмите **«Синхронизировать записи»**

## Как работает синхронизация

- Загружаются записи за текущий месяц
- Имена клиентов добавляются в календарь
- Статус посещения (пришёл/не пришёл) сохраняется
- Существующие записи не перезаписываются

## API YClients

Документация: https://developer.yclients.com/ru/

### Используемые методы

- `POST /api/v1/auth` — авторизация пользователя
- `GET /api/v1/records/{company_id}` — получение записей
- `GET /api/v1/clients/{company_id}` — получение клиентов

### Лимиты

- 200 запросов в минуту
- 5 запросов в секунду на IP
