# Что осталось доделать

Состояние на 13.08.2026. Большая работа закрыта: приложение обновляет себя
само, токены YClients уехали на сервер, старый push-контур погашен, версия и
тег поднимаются при слиянии PR. Осталась доводка — четырьмя кусками, ни один
не срочный, но два из них со временем дорожают.

Подробный план по этапам, по которому работает агент, — [TASKS.md](TASKS.md).

## Коротко

| # | Что | Зачем | Кто |
|---|---|---|---|
| 1 | Ротация `partner_token` YClients | Старый лежал в каждом APK до `0.1.0` и секретом больше не является | Владелец |
| 2 | Убрать `server/` и `neiro-push-events/` | Два мёртвых сервиса в репозитории путают при чтении | Агент |
| 3 | Скриншоты | README без картинок, в RuStore без них не пустят | Владелец снимает, агент раскладывает |
| 4 | Крайние случаи обновления | Проверен только счастливый путь | Владелец |
| 5 | Первый живой авто-релиз | Автоматика написана, но ни разу не срабатывала | Владелец сливает, агент смотрит |
| 6 | `mapping.txt` по 51 МБ в релизе | В 20 раз больше APK, 0,3 ГБ на шести релизах | Агент |

## Почему в таком порядке

**Ротация токена — первой.** Это единственный пункт с настоящим риском:
`partner_token` уехал в каждый публично выложенный APK версий до `0.1.0`, и
любой, кто его вынул, ходит в YClients от имени владельца. Пока старые сборки
работали, менять ключ было нельзя — они бы отвалились. Теперь можно: сервис,
который их обслуживал, погашен 13.08.2026. Каждый день ожидания — день, когда
ключ ещё действует.

**Первый авто-релиз — вторым**, потому что он проверяет то, чем дальше будут
выпускаться все остальные пункты. Сломано — узнать об этом лучше сейчас, на
правке документации, а не на важном исправлении.

**Скриншоты — третьими.** Без них карточка проекта выглядит недоделанной, а в
RuStore заявку просто не примут. Работа не сложная, но её нельзя поручить
агенту целиком: снимать надо на живом телефоне и на выдуманных именах — на
настоящих скриншотах видны имена учеников, и из публичного репозитория их уже
не отозвать.

**Уборка и `mapping` — последними.** Ни то, ни другое ничего не ломает
сегодня. Мёртвый код мешает только читающему, а лишние 50 МБ на релиз — только
хранилищу.

**Крайние случаи обновления** идут отдельной дорожкой: они проверяются на
телефоне и не блокируют ничего из остального. Обычное обновление работает —
это доказано переходами `0.1.3` → `0.1.4` → `0.1.5`. Не проверено, что
приложение красиво себя ведёт, когда что-то идёт не так: подменена сумма,
чужая подпись, оборвалась сеть, Android старее 12.
