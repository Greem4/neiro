# Дорожная карта фиксов по аудиту 14.08.2026

Четыре волны по риску. Внутри волны порядок имеет значение: каждый следующий
пункт ложится на уже исправленное. Один пункт = один коммит, сообщение — одной
строкой на русском (правило [`CLAUDE.md`](../../CLAUDE.md)).

**Порядок волн и объём — решение пользователя.** Ниже предложение, а не план к
исполнению. Разбор каждого пункта — в [FINDINGS.md](FINDINGS.md).

---

Три пункта, все небольшие. После них можно спокойно смотреть остальное.

| # | Что сделать | Файлы | Заготовка коммита |
|---|---|---|---|
| [S1](FINDINGS.md#s1-высоко--инкрементальный-live-sync-стирает-текущий-месяц-при-пустом-ответе-api) | Прогнать перезапрос месяца через `shouldApplySyncMerge` перед слиянием; при отказе вернуть `Failure` и не двигать метку live-опроса | `sync/YClientsCalendarSync.kt` | `Не стираю месяц по пустому ответу в live-синке` |
| [K2](FINDINGS.md#k2-высоко--невалидный-fcm-токен-выкидывает-пользователя-из-аккаунта) | По `token_invalid` обнулять `fcm_token`, а не удалять строку устройства | `neiro-push/app/poller.py`, `database.py` | `Не выкидываю устройство из-за мёртвого токена FCM` |
| [K1](FINDINGS.md#k1-высоко--лимит-попыток-входа-обходится-подменой-заголовка) | Брать адрес из `X-Real-IP` (его ставит nginx из `$remote_addr`), а не из первого элемента `X-Forwarded-For` | `neiro-push/app/ratelimit.py` | `Считаю лимит входа по настоящему адресу клиента` |

**Перед `K1`** проверить на VPS, что `proxy_set_header X-Real-IP $remote_addr`
действительно в конфиге (в `scripts/patch-vps-nginx-v1.sh:44` он есть, но
живой конфиг мог разойтись):

```
ssh <vps> "grep -n 'X-Real-IP\|X-Forwarded-For' /etc/nginx/sites-enabled/*"
```

**`S1` — тест обязателен.** Инкрементальный синк, где перезапрос текущего месяца
вернул пустой список, а в календаре есть ученики: месяц не должен измениться.
Это ровно тот класс, который аудит 23.07.26 ловил в полном синке.

## Вне дорожной карты

- **Ротация `NEIRO_PUSH_API_KEY`** — ручное действие на Pi, тянется с аудита
  23.07.26. Ключи из git-истории по-прежнему скомпрометированы.
  `YCLIENTS_PARTNER_TOKEN` из APK уже ушёл и ротируется без пересборки.
- **Переписывание git-истории** (`git filter-repo`) — решение пользователя.
- **Firebase BOM 33 → 34** — ломающее изменение, отдельным заходом.
- **Ночное окно опроса** (`QUIET_START_HOUR` без парного «конца тишины») —
  обсуждалось 11.08.2026, решение отложено осознанно. Чинить — значит менять,
  когда ночью приходят уведомления; сначала нужно решить, нужно ли окно вообще
  и с какого по какой час.
- **`REPORT.md` пакета 30.07.2026** — не написан. Сверка фиксов есть в
  [FINDINGS.md § Сверка](FINDINGS.md#сверка-фиксов-аудита-30072026);
  оформлять отчёт задним числом смысла нет.
