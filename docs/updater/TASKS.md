# План работ

Этап = законченная порция = один коммит. Порядок важен: каждый следующий этап
опирается на предыдущий и проверяется отдельно. Не сваливать несколько этапов
в один коммит — в таком коммите незамеченной проезжает поломка, и его
невозможно откатить по частям.

Сборку и проверку на устройстве делает владелец проекта: агент Gradle не
запускает. Поэтому у каждого этапа критерий готовности написан так, чтобы его
можно было проверить глазами по коду или одной командой.

Легенда: `[ ]` не начато, `[~]` в работе, `[x]` готово.

## Этап 11 — проверка на устройстве

Не пишется код, но без этого этапа работа не закончена. Проверяется на живом
телефоне, каждый пункт — отдельно.

- [ ] Обновление поверх: календарь, архив, профиль, настройки, токены YClients
      на месте
- [ ] Push продолжают приходить после обновления (сборка из CI содержит
      `google-services.json`)
- [ ] Отказ в системном диалоге — состояние возвращается в `Available`
- [ ] Обрыв сети посреди закачки — внятная ошибка, файл удалён
- [ ] Подменённая сумма в `SHA256SUMS.txt` — `ChecksumMismatch`, установка не
      начинается
- [ ] APK, подписанный другим ключом, — `SignatureMismatch`
- [ ] Android 12+: обновление ставится без системного диалога
- [ ] Android ниже 12 (или эмулятор API 24) — путь с диалогом работает
- [ ] Сборка, установленная через `adb`, обновляется; debug-сборка молчит
- [ ] `ru.vk.store` как installer — самообновление выключено, показана строка
      про магазин

Как проверять, не выпуская релизы: собрать локально версию с `VERSION=0.0.9`,
поставить её на телефон — и настоящий релиз `0.1.0` станет для неё
обновлением. Так проходится весь цикл на одном реальном релизе.
