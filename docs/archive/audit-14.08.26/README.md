## Что изменилось в системе с прошлого аудита

Разбирать пришлось во многом новую систему:

- **Ключи YClients ушли с телефона.** `partner_token`, `user_token`,
  `company_id` и `staff_id` живут в `.env` на Pi; приложение хранит только
  `device_token`, а старые ключи вычищаются из шифрованных prefs при каждом
  старте. Это закрывает пункты 4.1 и 4.3 из
  [OUT_OF_SCOPE](../audit-17.07.26/OUT_OF_SCOPE.md#4-изменения-требующие-backend).
- **Два бэкенда заменены одним.** `server/` (1 329 строк) и
  `neiro-push-events/` (4 833) удалены; на их месте `neiro-push` — 3 834 строки
  приложения и 2 632 строки тестов.
- **Появилось самообновление** — 18 файлов, 2 100 строк, отдельный канал
  уведомлений, экран «О программе», два release-workflow и контракт релиза
  (тег `vX.Y.Z`, `neiro-<версия>.apk`, `SHA256SUMS.txt`).
- **Сменилась схема версии**: `0.6.10.1` → `0.1.6`, единый источник в
  `version.properties`, `versionCode` по формуле, которую CI сверяет с тегом.

## Ограничения этого захода

- Gradle не запускался (правило проекта) — сборка, юнит-тесты и проверки на
  устройстве за пользователем;
- содержимое `.env` на Pi и живой конфиг nginx на VPS из репозитория не видны:
  `K1` описан по коду скрипта `patch-vps-nginx-v1.sh`, перед фиксом это стоит
  подтвердить на сервере;
- пункты из [OUT_OF_SCOPE.md](../audit-17.07.26/OUT_OF_SCOPE.md)
  находками не считались (DI, god-composables, ключ приложения в BuildConfig,
  authoritative wipe текущего месяца, архив из `cachedState`,
  `LaunchedEffect(initialNames)`, hardcoded строки, полная перезапись JSON в
  лентах уведомлений);
- ночное окно опроса на сервере (`QUIET_START_HOUR` без парного «конца тишины»)
  находкой не считается: обсуждалось 11.08.2026, решение отложено осознанно;
- `SessionMetaStore` пишется, но никем не читается — это записано как
  осознанное решение в самом файле, находкой не считается.
