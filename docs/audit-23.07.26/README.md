## Главное (TL;DR)

**Критично (3):**

1. **B1** — в git закоммичен `app/release/app-release.aab` с запечёнными `NEIRO_PUSH_API_KEY` и `YCLIENTS_PARTNER_TOKEN` → убрать из репо и **ротировать ключи**.
2. **S1** — `finally` в keepalive/live-воркерах переустанавливает цепочку даже после отмены при logout; `runCatching` глотает `CancellationException`.
3. **N1** — напоминания о занятиях могут теряться навсегда: окно fallback-проверки ±7 мин уже периода 15 мин, а пересоздание воркеров при каждом sync пропускает уже «просроченные» тайминги.

**Высоко (16):** гонка 401-logout с новым входом (D1), «призраки» при переносе записи (S4), отсутствие foreground-опроса при push (S3), потеря событий и in-app ленты без разрешения на уведомления (N2), гонка перепланирования сводок (N3), неатомарная смена цены (D2), cold snapshotsFlow без shareIn (D3), мёртвая перезапись архива (U1), порча формата интенсива без времени (U2), закрытие дня после process death (U3), залипание свайпа (U4), смена аккаунта без формы входа (P1), двойной сабмит логина (P2), рассинхрон тумблера уведомлений (P3), устаревший baseline-профиль (B2), сломанный androidTest (B3).
