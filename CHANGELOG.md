# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), нумерация —
[семантическая](https://semver.org/lang/ru/). Записи здесь пишутся для того,
кто пользуется приложением, а не для того, кто читает код: «что изменилось у
меня на экране», а не «какой класс переехал».

## [Не выпущено]

Пока пусто. Сюда дописывается изменение, заметное пользователю, — тем же PR,
которым оно вносится, а не по памяти в день выпуска. Заголовки внутри:
«Добавлено», «Изменено», «Исправлено», «Убрано».

## [0.1.1] — 2026-08-11

### Добавлено

- **Проверка новых версий** — приложение раз в сутки спрашивает GitHub, не
  вышла ли версия новее, и при открытии, если давно не спрашивало. Пока
  проверка молчаливая: сообщение о найденной версии и обновление одним
  нажатием появятся в следующих выпусках.

## [0.1.0] — 2026-08-11

Первый публичный выпуск. Приложение к этому моменту умеет:

### Добавлено

- **Календарь месяца** — занятия и суммы по дням, быстрый переход к сегодня,
  выбор месяца оверлеем.
- **День целиком** — таймлайн занятий, статусы «подтвердил / пришёл / не
  пришёл», правка вручную и перенос.
- **Деньги** — расчёт по ставкам с учётом налога, годовая статистика и графики
  по месяцам, факт и прогноз разделены.
- **Уведомления** — напоминание перед занятием, утренний и вечерний дайджест,
  push о новой записи, отмене и переносе. События присылает собственный
  сервис: приложение не опрашивает YClients само и не будит телефон впустую.
- **Архив** — своя история занятий помимо YClients: офлайн-правки, экспорт и
  импорт JSON, журнал уведомлений.
- **Офлайн-режим** — всё читается из локального хранилища; сеть нужна для
  обновления данных, а не для запуска приложения.
- **Вход через свой сервис** — токены YClients живут на сервере владельца,
  в приложение они не попадают; устройство отзывается кнопкой.

### Известные ограничения

- Самообновление приложения ещё пишется — эта версия ставится и обновляется
  вручную, файлом со страницы релизов.
- Приложение рассчитано на одного педагога и один филиал.
