# Baseline profile для холодного и тёплого старта Neiro.
# Заранее AOT-компилируем горячий путь: Application, Activity, главный экран и DataStore.
#
# Правила сверены 14.08.2026 по mapping-файлу R8 от релиза 0.1.6 (его app/src
# совпадает с этим коммитом). Правила пишутся в исходных именах, а переводит их
# в имена собранного APK сам AGP по mapping — поэтому сверять надо по нему, а не
# по dex, где имена уже переименованы.
#
# Правило, чью сигнатуру подтвердить не удалось, из файла удалено: молча не
# матчащееся правило хуже отсутствующего, потому что создаёт видимость покрытия.
# Так ушли CalendarGrid, DayCard, CalendarHeader, StatCard, SessionParser,
# CalendarDataStoreProvider, computeMonthStats и rememberCalendarMonthStats —
# R8 слил или заинлайнил эти классы целиком, и в mapping их больше нет.
#
# Отсюда же вывод: файл, написанный руками, для этого приложения живёт до
# первой перестройки главного экрана. Постоянное решение — генерация профиля
# модулем :macrobenchmark, он рядом в репозитории (docs/audit-14.08.26/REPORT.md).
